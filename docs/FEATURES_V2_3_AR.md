# دليل مميزات 3Esnap v2.3.0

## 1. الخزنة بالبصمة

المكتبة → قائمة الملف (⋯) → **إخفاء الملف في الخزنة بالبصمة** → المصادقة → تأكيد. بعد التشفير وحذف النسخة العامة يظهر الملف في تبويب **الخزنة** فقط. التبويب لا يفتح إلا بمصادقة حيوية قوية. داخل الخزنة يمكنك معاينة الملف أو إرجاعه للتنزيلات أو حذفه نهائيًا.

**تحذير:** لا تحذف التطبيق ولا تمسح بياناته بوجود ملفات مهمة داخل الخزنة: مفتاح التشفير والملفات ستُفقد. احتفظ بنسخة خارج التطبيق قبل الإخفاء. الإخفاء لمستند مستورد يتوقف على إذن حذف الأصل، وقد يفشل بأمان إذا رفض موفر الملفات.

## 2. التحميل التلقائي والاسترجاع عند رجوع الشبكة

من «تنزيل» أو «الإعدادات» فعّل **تنزيل تلقائي بعد الفحص**. عند اكتمال فحص الرابط تتم جدولة تنزيل بالجودة المختارة بعد حوالي 3 ثوانٍ. جدولة Android عبر `WorkManager` تعني أن الطلب يمكنه العمل في الخلفية، لكن نظام الهاتف قد يؤخر التنفيذ حسب ظروف الشبكة والبطارية.

عند انقطاع الشبكة أو أخطاء اتصال عابرة يُعاد جدولة التنزيل بعد عودة الاتصال، مع تراجع تصاعدي وحد أقصى للمحاولات. **ليست ميزة استكمال من نفس نسبة البايت:** قد يبدأ نقل الملف من جديد. الرابط الذي يحتاج تسجيل دخول أو تغير مصدره قد يفشل نهائيًا ويحتاج إعادة المحاولة اليدوية.

## 3. حفظ GIF من الفيديو

افتح فيديو من المكتبة → «قص/تحرير» → حدد بداية ونهاية **لا تتجاوز 15 ثانية**. يمكنك تطبيق قص الإطار (Crop) أولًا، ثم **حفظ GIF** أو **مشاركة GIF**. يتحول الجزء إلى GIF متحرك صامت ويُضاف إلى المكتبة دون تغيير الفيديو الأصلي. دقة الإخراج محدودة لتقليل حجم الملف.

## 4. تخفيف الموسيقى الخلفية — تجربة

عند قص فيديو أو صوت، فعّل **تخفيف الموسيقى/الضوضاء (تجريبي)**. يستخدم التطبيق مرشح ترددات وتقليل ضوضاء داخل FFmpeg، وقد يُحسّن بعض المقاطع الصوتية؛ **لا يفصل الغناء أو الكلام عن الموسيقى آليًا مثل Demucs / UVR**. احتفظ بالملف الأصلي وقارن الناتج قبل المشاركة.

## 5. التصنيف والبحث

كل تنزيل جديد يحصل على تصنيف مقترح محليًا بحسب الكلمات في العنوان، مثل تعليم / ألعاب / أخبار / موسيقى / رياضة، أو عام. لتغييره: المكتبة → قائمة الملف → **تعديل التصنيف**. في المكتبة يمكنك البحث بالاسم أو رابط المصدر والتصفية حسب التصنيف ونوع الملف (فيديو/صوت/GIF).

## 6. التحديث دون حذف

يجب أن تتطابق **هوية التطبيق Application ID، ومفتاح التوقيع، ويزيد رقم الإصدار** لكي يثبت Android APK الجديدة فوق القديمة. هذا التحديث يبقي `com.threee.snap` و`com.threee.snap.debug` كما هما. لا تخلط نسخة Debug مع Release ولا تحذف تطبيقًا يحوي ملفات الخزنة لحل تعارض التوقيع.

**حالة التحقق:** هذه حزمة مصدر بميزات منطقية جديدة اجتازت فحوص المصدر ومحاكاة الواجهة واختبار GIF بـFFmpeg للحاسوب. **لم يتم تجميع APK v2.3.0 أو اختبار الخزنة أو WorkManager على هاتف فعلي** في بيئة التسليم.
