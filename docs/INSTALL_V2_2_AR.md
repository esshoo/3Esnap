# رفع تحديث 3Esnap v2.2.0

> تحديث مصدر مبني على المستودع `esshoo/3Esnap` عند commit `c335cc8195d2b56c8c087d06582c191d3e443a84`. هذا ملف overlay لا يحتوي على Git history أو مفاتيح توقيع.

## ما الجديد؟

1. استرجاع ملف JSON الذي صدّرته من 3Esnap 2.1 أو الأقدم. **الإعدادات → استرجاع الروابط من نسخة JSON**. لا تخلط بينه وبين «إضافة ملفات قديمة» للفيديو/الصوت.
2. مطابقة الملفات المستوردة من الهاتف مع سجلات الروابط بالاسم والصيغة، ومنع التكرارات، وإعادة التنزيل من الرابط عند غياب الملف.
3. شاشة مستقلة لقص إطار الفيديو (Crop) بزوايا قابلة للسحب وإطار قابل للتحريك، نسب حر/1:1/9:16/16:9، مع تطبيق ثم حفظ/مشاركة المقطع.
4. زيادة رقم `versionCode` إلى `22000 + GITHUB_RUN_NUMBER`، مع الحفاظ على Application IDs الحالية. **لكن زيادة الرقم وحدها لا تحل اختلاف مفتاح التوقيع**؛ راجع `UPDATE_AND_RESTORE_AR.md`.

## طريقة الرفع السريعة

- افتح مجلد المشروع المستنسخ في **GitHub Desktop → Repository → Show in Explorer**.
- فك ضغط `3Esnap-v2.2.0-PATCH.zip`، وانسخ **المحتويات** إلى جذر المستودع (`app` و`docs` و`tools` بجوار `gradlew`). لا تنسخ مجلد ZIP كأنه subfolder.
- وافق على استبدال الملفات، ثم راجع Changes. **لا تحذف `.git` أو مجلدات أخرى أو ملفات `LICENSE` وGradle Wrapper**.
- من GitHub Desktop اعمل Commit ثم Push. أو من Terminal داخل مجلد المشروع:

```powershell
git status
git diff --stat
git add app/ docs/ tools/ tests/ README.md DELIVERY_MANIFEST.json
git commit -m "Restore 3Esnap JSON backups and add separate video crop screen"
git push origin main
```

- انتقل إلى GitHub **Actions → Build 3Esnap APK** وانتظر إتمام كل خطوات الاختبار وLint وتجميع APK. **لا تحذف النسخة المثبتة** لمجرد أن GitHub انتهى بنجاح؛ تأكد من توقيع نسخة APK التي ستثبتها.
- نزّل `3Esnap-debug-APK-...` للنسخ التجريبية، أو `3Esnap-signed-APK-...` إذا جهزت أسرار توقيع Release الثابتة.

## استعادة البيانات دون خسارة

1. احتفظ بملف JSON الصادر سابقًا في Downloads أو السحابة. لا تمسح نسخة منه.
2. بعد تثبيت نسخة موقعة متوافقة أو في تطبيق جديد مستقل، افتح الإعدادات واختر **استرجاع الروابط من نسخة JSON**.
3. بعد ظهور السجلات، إذا بقيت ملفات الفيديو في الجهاز، اضغط **إضافة ملفات قديمة** وحددها من منتقي Android؛ سيتم ربط المتطابق منها بسجله الأصلي.
4. الملف المفقود الذي له رابط محفوظ يظهر بخيار **إعادة تنزيل**.
5. بعد التجربة صدر نسخة JSON ثانية واحفظها خارج التطبيق.

**مهم:** نسخ JSON لا تحتوي على بايتات الفيديو أو الصور؛ واستيرادها لا ينشئ فيديو جديدًا من تلقاء نفسه.

## الحالة التقنية

مرّت اختبارات Java (قواعد النسخ، EditPlan، سياسات التنزيل، وتحليل صياغة Java)، والتحقق البنيوي، وJavaScript، واختبارات Chromium الافتراضية. لم يُجر بناء Android SDK ولا اختبار فعلي على هاتف لهذا الإصدار. اختبار APK وميزات Crop وSQLite على الهاتف لازم قبل اعتماد النسخة.
